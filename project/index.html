Architecture verdict

Không phải MVVM thuần.

Flutter

Feature-first layered

View và logic điều phối vẫn cùng nằm trong State<Page>. Repository và Service đảm nhiệm truy cập dữ liệu nhưng chưa có ViewModel riêng.

Page → Repository → ApiService → REST
